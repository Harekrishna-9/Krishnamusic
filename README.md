# Krishna Music

यह एक cinematic, responsive single-page music website है।

## चलाने का तरीका
1. `assets/music/` folder में अपने MP3 रखें:
   - song1.mp3
   - song2.mp3
   - song3.mp3
2. गानों के नाम बदलने के लिए `app.js` के ऊपर `playlist` array edit करें।
3. `index.html` browser में खोलें।
4. GitHub Pages पर upload करने के लिए पूरा folder repository में push करें।

## Files
- index.html
- style.css
- app.js
- assets/music/

Design original है और screenshot से केवल cinematic/highway vibe की inspiration ली गई है।
